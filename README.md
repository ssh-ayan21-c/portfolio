# Ayan Mekrani - Developer Portfolio

Welcome to my personal portfolio! This project is an interactive, highly-animated web experience designed to showcase my projects, skills, and contact information. 

## Features

- **Interactive Physics Engine:** A unique landing page powered by `Matter.js` featuring draggable, physical tech logos cascading into view.
- **Scroll Hijacking & Typography:** Uses `framer-motion` for complex scroll-driven animations, transforming typography seamlessly from one font family to another.
- **Custom Cursor & Smooth Scrolling:** Features a customized pointer with spring-physics trailing dots, and a custom wave-like vertical scrollbar.
- **Modern Layouts:** Designed entirely with TailwindCSS, leveraging features like `mix-blend-difference` to achieve dynamic, high-contrast text against diverse backgrounds.
- **Fully Responsive:** Adapts from mobile to large desktop displays gracefully without sacrificing animations.

## Tech Stack

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Framer Motion](https://www.framer.com/motion/)
- [Matter.js](https://brm.io/matter-js/)

## Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Run the development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```
